# SNAP EBT monthly deposit-day rules by U.S. state

The day of the month on which SNAP benefits are loaded to EBT cards in 24 U.S. states, one row per key range, as each state agency publishes it.

Site: https://ebt.govsimple.org/

## Files

| File | Rows |
|---|---|
| `ebt_deposit_rules.csv` | 259 |

## Columns

**`ebt_deposit_rules.csv`**

- `state`: postal code
- `state_name`: state
- `agency`: the state agency
- `key_type`: kind of key the state uses
- `key`: what the key is, in the site's words
- `birth_month`: Missouri only: month of birth, 1 to 12
- `key_from`: first key value of the row
- `key_to`: last key value of the row
- `day_of_month`: day of the month SNAP benefits are made available
- `source`: the agency page or document the rule was read from
- `source_url`: its address

## How it was checked

For each state the agency's own page or document was read and a copy saved on the retrieval date; the rule was copied into a table and compared with the saved copy by a separate program with its own reader for each state. The first 15 states were also reviewed independently before launch, and the nine added later (AL, AZ, CA, GA, LA, MA, MO, RI, WY) on 2026-11-24. Known soft spots: California's current brochure prints no line for digit 0, and 0 = 10th comes from an older printing of the same brochure; Alabama's manual dates from 2022; Louisiana's table is on a page written during the 2025 federal shutdown that restates the usual schedule; Texas households certified before May 2023 keep an older schedule.

## Left out

States whose rule could not be confirmed from an official page we could read are not listed; the site's About page names each with the reason. Weekend and holiday handling, the time of day, caveats and the agencies' own sentences are on the site's state pages and are not in this file. State agencies publish these schedules without an open licence, so no agency text is reproduced here: only the facts of each schedule, in our own table. This is not a government dataset; the agency's page governs.
